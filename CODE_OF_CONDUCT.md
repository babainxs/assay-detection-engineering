# Code of Conduct

This project follows the spirit of the Contributor Covenant. Be respectful and constructive. Criticize ideas, not people. No harassment, discrimination, doxxing or personal attacks. Maintainers may edit, hide or remove contributions that break these rules and may block repeat offenders.
