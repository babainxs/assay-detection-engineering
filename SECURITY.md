# Security policy

ASSAY is a specification, not running software. A flaw can still do harm: guidance or a schema that creates a detection blind spot, or a pipeline pattern that can be exploited.

## Reporting
Do not open a public issue for such a flaw. Use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability"). Include the affected file or requirement ID, how it could be abused or what it would miss, and a suggested fix if you have one.

## What to expect (proposed)
Acknowledgement within 7 days, a decision on severity and a fix plan within 30 days, and credit in the changelog if you want it.
